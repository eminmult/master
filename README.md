# itez.app — monorepo

Home-services marketplace operating in Azerbaijan (primarily Baku). Connects clients with vetted plumbers, electricians, welders, locksmiths, painters, cleaners and 60+ other trades.

## Layout

```
master-site/          Web platform
  backend/            Laravel 11 (PHP 8.4) — API, auth, payments, realtime
  frontend/           Nuxt 3 (Vue 3) — SSR site at itez.app
  sse/                Node SSE relay — primary realtime transport (CF-Flexible-friendly)
  docker-compose.yml  Full stack: Postgres, Redis, Reverb (Laravel WebSockets)
  backup.sh           pg_dump → backups/ (excluded from git)

master-mobile/        Flutter 3.x — Android + iOS client
```

## Quick start (web)

```bash
cd master-site
cp backend/.env.example backend/.env   # fill APP_KEY, DB_*, MAIL_*, GEMINI_KEY
docker compose up -d
docker exec master-api php artisan migrate --seed
```

The site is then on http://localhost:8093 (Nuxt) with API on /api/v1/*.

## Quick start (mobile)

```bash
cd master-mobile
cp .env.example .env
docker compose run --rm master-mobile-dev flutter pub get
docker compose run --rm master-mobile-dev flutter build apk --release \
  --dart-define=API_BASE_URL=https://itez.app/api/v1
```

## SEO architecture

See `master-site/frontend/server/routes/sitemap.xml.ts`, `robots.txt.ts`, `llms.txt.ts`
and `composables/useSeoHead.ts`. Localized slugs per category and per master are
generated by `php artisan seo:translate-categories`; long-form category content
by `php artisan seo:generate-category-content` (both backed by Gemini).

## Conventions

- All user-facing text goes through ARB (mobile) or locales/*.json (site).
  Never hardcode strings.
- Phone numbers are never displayed to either party — in-app voice calls only.
- Hide empty categories from public listings.
- After `docker compose build`, prune the build cache + dangling images.
